# SMB DevOps Agent Kernel

Base multiagente customizável para automação de operações (DevOps) em pequenas e médias empresas.

Status: em construção — aprendendo do zero (Python, Docker, agentes de IA) enquanto desenvolvo.

## Por quê
PMEs raramente têm equipe de DevOps/SRE dedicada. Este projeto constrói uma base leve e
customizável de agentes de IA para cobrir as necessidades operacionais mais comuns desse
porte de empresa, começando por triagem de incidentes/alertas e verificação de backup.
